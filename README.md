# Strange Room

一个基于 WebRTC 的端到端加密临时协作空间，支持白板、代码编辑和实时聊天。

## 项目简介

Strange Room 是一个专为临时协作设计的 Web 应用。它采用点对点（P2P）通信架构，所有数据直接在用户设备之间传输，服务器仅负责信令交换，不存储任何业务数据。房间具有自动销毁机制，在设定的有效期结束后永久删除所有数据。

## 核心特性

### 安全与隐私
- **端到端加密**：使用 Web Crypto API 实现真正的端到端加密，密钥仅在客户端生成和存储
- **零数据存储**：服务器仅处理信令交换，不保存任何聊天内容、白板数据或代码
- **自动销毁**：支持 1/6/24/48 小时有效期，到期后房间数据自动清除
- **空闲超时**：当房间内没有任何在线用户超过设定时间（5/15/30/60 分钟）时自动销毁
- **匿名使用**：无需注册登录，不收集个人信息
- **设备指纹**：基于浏览器特征生成唯一用户标识，确保跨会话一致性

### 协作功能
- **实时白板**：多人同时绘图，支持画笔、形状、橡皮擦
- **代码协同**：内置 Monaco 编辑器，支持多种编程语言语法高亮（离线可用）
- **实时聊天**：群组聊天，支持文本消息
- **光标追踪**：实时显示其他用户的鼠标位置

### 技术优势
- **P2P 架构**：数据不经过中转服务器
- **低延迟**：基于 WebRTC 的实时通信
- **完全离线可用**：Monaco Editor 和所有字体资源本地化，无需外部 CDN
- **跨平台**：支持桌面和移动端浏览器

### 前端技术栈
- **框架**: Next.js 14 (App Router)
- **UI 组件**: Ant Design 5
- **样式**: Tailwind CSS 4
- **协同编辑**: Yjs + y-websocket (二进制协议)
- **代码编辑**: Monaco Editor (本地化，完全离线可用)
- **状态管理**: React Hooks
- **加密**: Web Crypto API (端到端加密)
- **图标**: Lucide React
- **字体**: 本地字体 (Consolas, Monaco, Courier New, cursive)

### 后端技术栈
- **信令服务器**: Node.js + WebSocket (ws)
- **P2P 通信**: WebRTC
- **数据同步**: Yjs 协同引擎
- **协议**: WebSocket 二进制消息转发
- **房间管理**: 内存存储，支持空闲超时自动清理

### 核心模块说明

#### 1. 信令服务器 (`server/signaling-server.js`)
- **职责**：房间管理、令牌验证、WebSocket 消息转发、空闲超时检测
- **特点**：零数据存储，仅转发二进制消息
- **空闲超时机制**：每分钟检查所有房间，无在线用户超过设定时间自动销毁
- **API 端点**：
  - `POST /api/room/create` - 创建房间 (支持空闲超时配置)
  - `GET /api/room/check/:id` - 检查房间是否存在
  - `POST /api/token/generate` - 生成访问令牌
  - `POST /api/token/validate` - 验证访问令牌
  - `POST /api/room/destroy` - 销毁房间
  - `GET /health` - 健康检查

#### 2. 端到端加密 (`src/lib/crypto/`)
- **e2e-crypto.ts**：AES-GCM 256 位加密/解密
- **key-manager.ts**：密钥生成、存储和分享

#### 3. Yjs 协同引擎 (`src/lib/yjs/`)
- **y-doc.ts**：Yjs 文档初始化和类型管理
- **y-provider.ts**：WebSocket 连接和消息同步

#### 4. 房间管理 (`src/lib/room/`)
- **room-manager.ts**：房间生命周期管理、倒计时、空闲超时检测、销毁

#### 5. 代码编辑器 (`src/components/Editor/`)
- **MonacoEditor.tsx**：Monaco 编辑器组件，使用本地资源，完全离线可用
- **SimpleCodeEditor.tsx**：轻量级代码编辑器（备用方案）

## 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装步骤

1. 克隆项目
```bash
git clone https://github.com/BlkSword/Strange-room.git
cd Strange-room
```

2. 安装前端依赖
```bash
npm install
```

3. 安装服务器依赖
```bash
cd server
npm install
cd ..
```

### 同时启动前后端（推荐）

```bash
npm run dev:all
```

4. 启动信令服务器
```bash
npm run server
```

5. 启动前端开发服务器
```bash
npm run dev
```

6. 访问应用

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

### 生产部署

1. 构建前端
```bash
npm run build
```

2. 启动生产服务器
```bash
npm start
```

## 使用指南

### 创建房间
1. 访问主页，点击"创建房间"按钮
2. 输入房间名称（可选）和你的昵称
3. 选择房间有效期：
   - 1 小时
   - 6 小时
   - 24 小时
   - 48 小时
4. 选择空闲超时：
   - 5 分钟
   - 15 分钟
   - 30 分钟
   - 1 小时
5. 确认创建，系统生成邀请链接

### 加入房间
1. 通过创建者分享的邀请链接访问
2. 输入你的昵称
3. 点击"加入"按钮进入协作空间

### 房间功能
- **白板**：点击画笔工具开始绘图，支持多人同时编辑
- **代码编辑**：在编辑器中编写代码，支持语法高亮（完全离线可用）
- **聊天**：在聊天框输入消息，与房间成员实时交流
- **用户列表**：查看当前在线的所有用户

### 房间销毁机制
房间在以下任一情况发生时将被自动销毁：
1. **有效期到期**：超过设定的房间有效期（1/6/24/48 小时）
2. **空闲超时**：房间内没有任何在线用户超过设定的空闲时间（5/15/30/60 分钟）
3. **手动销毁**：房间创建者主动销毁房间

房间销毁后，所有数据将被永久删除，无法恢复。

## 离线可用性

本项目支持完全离线运行，无需任何外部网络请求：

1. **Monaco Editor 本地化**
   - 所有编辑器资源文件存储在 `public/monaco-editor/min/vs/`
   - 无需从 CDN 加载任何资源
   - 支持完整的代码编辑功能

2. **本地字体**
   - 使用系统默认字体
   - 无需从 Google Fonts 等外部服务加载

3. **离线部署**
   - 所有资源打包在项目内
   - 可在无网络环境下运行

## 安全说明

### 端到端加密
- 基于 AES-GCM 256 位加密算法
- 密钥在创建者浏览器本地生成，服务器无法获取
- 加密密钥通过邀请链接安全分享给房间成员
- 聊天消息在发送前加密，接收后解密
- 服务器仅转发加密数据，无法查看明文内容

### 数据传输
- 所有通信通过 Yjs + WebSocket 二进制协议
- 数据直接在用户浏览器之间同步
- 信令服务器仅交换连接信息，无法窥探通信内容
- WebSocket 连接在房间不存在时正确关闭，避免无效重连

### 数据存储
- 房间数据存储在浏览器 IndexedDB 中
- 本地加密存储，其他应用无法访问
- 房间销毁后本地数据同步清除
- 设备指纹存储在本地，确保同一设备上的用户 ID 一致性

### 隐私保护
- 无需注册账号，不收集个人信息
- 不使用 Cookie 或追踪技术
- 不连接第三方统计服务
- 用户 ID 基于昵称和设备指纹生成，同一昵称在不同设备上产生不同 ID
